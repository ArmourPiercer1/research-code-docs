### B.1 documentation-quality-evaluator (DQE) — v0.4.1 — **evaluator**
- **Purpose:** judge a research-software documentation artifact against hard gates HF-1…HF-15 + weighted 8-dimension rubric (non-compensatory rule) + two-layer no-context reader test; emit a machine-parseable two-axis verdict block (`SKILL.md:1-5`; verdict keys `make_grading_injection.py:88-95`). "Grades every other skill's output" (`SKILL.md:28`).
- **Trigger:** someone wants a doc graded/critiqued for quality, or a control flow needs its terminal quality gate (`SKILL.md:3`); orchestrator-only invocation (registry:48).
- **Non-trigger:** reviewing code (→ code-review), general prose editing (`SKILL.md:3`).
- **Inputs:** target doc bytes + explicit `evaluation_profile` (artifact_type, provenance_policy ∈ {controlled, legacy, external}, decision_mode ∈ {release-gate, audit}, evidence_requirement, reader_profile, output_mode — ADR-DQE-001:30-42; DQE must not silently infer provenance_policy/decision_mode) + harness refs (rubric.md, hard-fail.md, canonical-source-map.md, `SKILL.md:232-236`).
- **Outputs:** quality-report (KEY=VALUE verdict: QUALITY_BAND, GATE_DECISION, GATE_REASON, DOCUMENT_QUALITY, FACTUAL_VALIDITY, READER_TEST, CHECKER_STATUS, SOURCE_COVERAGE, CONFIDENCE, BLOCKERS, FINDING_CODES, EVALUATION_PROFILE, FILES_READ) + reader-test report. **Transient** per-run advisory output — "an ALLOW authorizes nothing" (release-manifest:50).
- **Read scope:** target doc + its cited sources (must be opened for FACTUAL_VALIDITY; unopened → UNVERIFIED); `whole_repo_allowed: false` (registry:63). **Write scope:** read_only, creates report files only (registry:62).
- **Dependencies:** upstream none (runs on any produced doc); downstream: documentation-refactor (advisory review stage), human reviewers, flows. **External L3:** none.
- **Schemas/checkers enforcing its artifacts/behavior:** runs ALL 15 checkers via `run_checks.py` (HARD frontmatter_check/status_vocab_check; SIGNAL state_number_consistency, completion_open_conflict, roadmap_stage_fields, agent_session_residue, artifact_role_mixing feed HF-13/14a/14b/15); `make_grading_injection.py` assembles isolated evaluator/reader/meta prompts.

## C. Eval harness as a subsystem

Location: `evals/skills/` (tracked) + `tests/corpus/` (tracked except `upstream/`) + `evals/skills/snapshots/` (git-ignored). Core constraint: **"do not install a skill to test it"** (evals/skills/README.md:15-20; docs/prompt.md:7) — every eval injects the skill's SKILL.md body into a fresh sub-agent.

**C.1 Runner.** Two kinds:
- *Deterministic:* `evals/skills/harness/checkers/run_checks.py <path> [--json] [--advisory-is-hard]` — walks a file/directory (skips .venv, node_modules, fixtures/, references/mattpocock-skills/), runs all tiers, prints JSON, exits 1 iff a HARD gate fails (run_checks.py:1-24, 46-104).
- *Model evals:* no single runner binary — the session orchestrator builds injection prompts (`make_injection.py` / `make_batch.py` / `make_grading_injection.py`), spawns sub-agents, and scores with `score_trigger.py` / `score_all.py` / `score_grading.py`; `validate_cases.py` validates case files (evals/skills/README.md:71-90; harness dir listing on disk: 10 .py files).

**C.2 Checker tiers** (run_checks.py:46-58; docstring lines 5-16):
- **HARD** (block; set exit code): `frontmatter_check` (HF-9 traceability front-matter), `status_vocab_check` (HF-3/HF-10 status/evidence legality).
- **ADVISORY** (report only unless `--advisory-is-hard`): `markdown_links_check`, `placeholders_check`, `interface_check` (Batch-2.5 12-field handoff contract; opt-in on `artifact_type:`; aliases produced_by_skill↔generated_by_skill, source_artifacts↔source_documents; interface_check.py:1-18), `flow_state_check` (Batch-3; HONEST BLOCKED rule; opt-in on `flow_status:`), `migration_map_check`, `rewrite_provenance_check`, `maintenance_impact_check` (Batch-5).
- **SIGNAL** (informational candidates for model adjudication of HF-13/14a/14b/15; NEVER block): `state_number_consistency`, `completion_open_conflict`, `roadmap_stage_fields`, `agent_session_residue`, `artifact_role_mixing`.
- **Standalone (NOT registered in run_checks.py):** `register_check.py` (decision-register validation; invoked directly by UDM, SKILL.md:113) — an orphan relative to the runner (see §G D5). `_textutils.py` shared helpers. 17 checker files total on disk.

**C.3 Injection mechanism.** `make_injection.py` (trigger/conflict): DECISION_CONTRACT ("evaluated for TRIGGERING behavior only… single JSON {decision, route_to, justification}", make_injection.py:22-37) + full SKILL.md body + case input → fresh sub-agent. `make_grading_injection.py` (task-quality): three roles with deliberately different context envelopes (make_grading_injection.py:10-27): `evaluator` = SKILL.md + hard-fail.md + rubric.md + canonical-source-map.md + target bytes + EVALUATOR_CONTRACT (the full profile/gate/verdict contract, lines 41-96); `reader` = ONLY target bytes + two-layer reader questions (no rubric, no hard-fail — anti-bias); `meta` = human annotation + evaluator output. **C.4 Blind-run protocol (DQE corpus).** `scripts/build_blind_suite.py` assembles a blind run dir: case document copied under a random UUID name, `params/<id>.yaml` carrying ONLY artifact_type + allowed profile (NO expected labels, NO class name), `.secret/mapping.tsv` readable only by the comparator, order shuffled (build_blind_suite.py:3-13).
